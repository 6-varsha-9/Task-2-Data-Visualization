# Task 2 - Data Visualization and Storytelling

## Objective

To create meaningful visualizations and derive business insights from sales data using Power BI.

Tool Used

* Power BI

Dataset

* Sample Superstore Dataset

Dashboard Components

* Total Sales KPI
* Total Profit KPI
* Total Orders KPI
* Sales by Category
* Profit by Category
* Sales Trend Over Time
* Sales by Region
* Top 10 States by Sales
* Profit vs Sales Analysis

Key Insights

* Technology generated the highest sales.
* Technology was the most profitable category.
* West region contributed a significant share of sales.
* California emerged as a top-performing state.
* Sales showed an overall positive trend over time.

Outcome

Developed a professional Power BI dashboard and learned data storytelling techniques using visual analytics.
